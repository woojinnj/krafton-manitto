# Jungle Manitto

서로를 몰래 응원하고 마지막 날 정체를 공개하는 정글 마니또 웹앱입니다. 2026년 크래프톤 정글 1주차 팀 프로젝트를 기반으로, `codex-version`의 개선을 이어 `astra-version`에서 프로필 편집과 게임 진행 경험을 다듬었습니다.

## 주요 기능

- 회원가입 및 쿠키 기반 JWT 로그인
- 관리자 전용 마니또 순환 배정
- 마니또 정보 조회와 공개 후 마니띠 확인
- 대시보드에서 이름·MBTI·바라는 점 수정, 입력 검증 및 저장 결과 안내
- 배정 대기·비공개·공개 상태에 맞춘 다음 행동 안내와 카드 숨기기
- 공개 후 마니띠 별점 등록 및 평가 완료 표시
- 평가받은 참가자의 누적 평균 랭킹, 공동 순위와 평가 횟수 표시
- 관리자 재배정 확인창과 요청 중 중복 클릭 방지
- 모바일부터 데스크톱까지 대응하는 반응형 UI
- 키보드 탐색, 포커스 표시, 모션 감소 등 접근성 지원

## 빠른 시작

Python 3.12 이상과 MongoDB가 필요합니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
set -a
source .env
set +a
flask --app app init-db
python app.py
```

브라우저에서 `http://127.0.0.1:5001`을 엽니다. `.env`는 자동으로 읽지 않으므로 위와 같이 데이터베이스 초기화와 서버 실행 **전에** 환경 변수를 로드해주세요. 새 셸을 열었을 때도 다시 로드해야 합니다.

## 게임 진행

1. 참가자가 가입하고 프로필을 준비합니다. 관리자 계정은 기존과 같이 DB에서 `role: "admin"`으로 지정합니다.
2. 관리자가 최소 3명의 참가자를 배정합니다. 관리자 자신은 배정에서 제외됩니다.
3. **내 마니또**는 내가 응원할 친구이고, **내 마니띠**는 나를 응원하는 친구입니다. 마니띠는 관리자가 공개한 뒤 확인할 수 있습니다.
4. 공개 후 배정당 한 번 별점을 등록합니다. 랭킹은 받은 별점의 누적 평균이며 동점자는 같은 순위를 갖습니다.
5. 새로 배정하면 공개 상태와 평가 여부가 초기화됩니다. 이전에 받은 별점의 누적 합계와 횟수는 유지됩니다.

다른 사용자가 바꾼 공개 상태와 최신 랭킹은 대시보드의 **진행 상태 새로고침**으로 확인합니다. 프로필 수정은 저장 즉시 내 프로필 카드에 반영되며, 비밀 카드와 프로필 응답은 브라우저에 캐시하지 않습니다.

## 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `MANITTO_ENV` | `development` | `production`일 때 운영 보안 설정을 검사합니다. |
| `JWT_SECRET_KEY` | 개발 전용 키 | 운영 환경에서는 32바이트 이상의 무작위 값이 필수입니다. |
| `MONGO_URI` | `mongodb://localhost:27017/` | MongoDB 연결 문자열입니다. |
| `MONGO_DB_NAME` | `manitto` | 사용할 데이터베이스 이름입니다. |
| `JWT_COOKIE_SECURE` | 운영 시 `true` | HTTPS에서만 인증 쿠키를 전송합니다. |
| `HOST` | `127.0.0.1` | 개발 서버 바인딩 주소입니다. |
| `PORT` | `5001` | 개발 서버 포트입니다. |

운영용 비밀키 생성 예시:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## 테스트

테스트는 외부 MongoDB 없이 메모리 저장소로 모든 핵심 흐름을 검증합니다.

```bash
python -m unittest discover -v
node --test tests/dashboard.test.cjs
```

Python 테스트 12개는 공개 페이지, 인증, 회원가입 검증, 관리자 권한, 배정, 공개 상태, 마니또·마니띠 조회, 공개 전·중복 별점 방지, 공동 순위, 프로필 수정과 보안 헤더를 확인합니다. Node.js 18 이상에서 실행하는 자바스크립트 테스트 7개는 CSRF 전달, 인증 만료, 서버·네트워크 오류와 재배정 확인·취소를 검증합니다. 실제 브라우저 및 MongoDB 통합 테스트는 별도로 필요합니다.
